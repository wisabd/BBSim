You can download all files in a directory.

And run the following commands from the IDE terminal

Step 0:  In your IDE go the the folder with these files using cd command

Step 1: Run the API      uvicorn api-raw:app --reload

Keep the API running 

Step 2: Open another terminal

Step 3: Type this to run the frontend python -m http.server 3000



Step 4: Open a browser tab and type http://localhost:3000

Then you can modify the parameters to run the simulation
